# SPK Pemilihan Tanaman Lahan - Metode SAW (Kelompok III)

Letakkan kelima file ini dalam SATU folder yang sama, lalu buka index.html
(klik dua kali, atau Live Server di VS Code).

- index.html : kerangka halaman (sidebar, topbar, dialog tambah/ubah lahan)
- style.css  : tampilan
- data.js    : data kriteria, tanaman, dan lahan (sintetis, dari generate.py)
- saw.js     : fungsi perhitungan SAW
- app.js     : isi halaman, rute (#hash), pengujian otomatis

Data lahan dan bobot yang diubah tersimpan di browser (localStorage).
Semua data berstatus sintetis dan hanya untuk pembelajaran.
